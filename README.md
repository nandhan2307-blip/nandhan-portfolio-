# Nandhan S S — Animated Portfolio

Open `index.html` in a browser.

Included:
- Scroll-driven story: Learn → Build → Create → Projects → Skills → Contact
- Animated portrait treatment using the supplied PDF portrait
- Responsive layout and reduced-motion support
- Project GitHub links
- Resume button using the supplied ATS resume
- No invented technical stack for the inaccessible Health Team 284 repository
- Pure HTML/CSS/JS with GSAP-style motion implemented in lightweight native JS/CSS, so it can be deployed directly on Vercel, GitHub Pages, Netlify, etc.

## Deploy
Upload the whole folder to a static host. Keep `assets/nandhan-photo.png` and `Nandhan-S-S-Resume.pdf` beside `index.html`.
